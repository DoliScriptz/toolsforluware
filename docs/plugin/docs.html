# LuWare Plugin API — AI Reference

You are writing a `.plug` plugin for LuWare. Use only the documented public API below. Do not invent functions, argument names, config fields, return values, or element types. Preserve the exact capitalization shown here.

## Plugin entry

A plugin can check the current game with:

```lua
if shared_info.Game ~= "Murder Mystery 2" then
    return
end
```

`shared_info.Game` is read-only game information.

## Tabs

```lua
local tab = shared_info.AddTab("My Plugin", "sparkles")
```

`shared_info.AddTab(name, icon)`
- `name`: string displayed as the plugin tab name.
- `icon`: string containing a Lucide icon name only, such as `sparkles`, `settings`, or `puzzle`.
- Do not use an image URL, asset ID, or custom icon object.
- Returns a tab handle.

## Groupboxes

```lua
local group = shared_info.AddGroupbox(tab, "Main", "Left")
local right = shared_info.AddGroupbox(tab, "Extras", "Right")
```

`shared_info.AddGroupbox(tab, name, side)`
- `tab`: tab handle returned by `AddTab`.
- `name`: string used as the groupbox title.
- `side`: exactly `"Left"` or `"Right"`.
- Returns a groupbox handle.

A tab handle also supports:

```lua
local group = tab:AddGroupbox("Main", "Left")
```

## Labels

```lua
local label = shared_info.AddLabel(group, "Waiting...")
label:SetText("Ready!")
```

`shared_info.AddLabel(group, text)`
- `group`: groupbox handle.
- `text`: string displayed by the label.
- Returns a label handle.
- Label handle method: `SetText(text)`.

## Toggle

```lua
local enabled = shared_info.AddToggle(group, "Enabled", {
    Default = true,
    Callback = function(value)
        print("Toggle callback:", value)
    end,
})

enabled:SetValue(false)
print(enabled:GetValue())
enabled:OnChanged(function(value)
    print("Changed:", value)
end)
```

`shared_info.AddToggle(group, name, config)`
- `group`: groupbox handle.
- `name`: string shown next to the toggle.
- `config.Default`: boolean initial value.
- `config.Callback`: function(value) called when the value changes.
- Returns a toggle handle.
- Handle methods: `GetValue()`, `SetValue(value)`, `OnChanged(callback)`, `RunChanged()`.
- `SetValue(value)` expects a boolean.

## Button

```lua
shared_info.AddButton(group, "Say Hello", {
    Callback = function()
        shared_info.Notify("Hello from my plugin!", 2)
    end,
})
```

`shared_info.AddButton(group, name, config)`
- `group`: groupbox handle.
- `name`: button text.
- `config.Callback`: function() called when the button is pressed.
- Does not use `Default`, `Min`, `Max`, `Prefix`, or `Suffix`.
- The documented button API is action-based; do not expect `GetValue()` or `SetValue()` on it.

## Slider

```lua
local speed = shared_info.AddSlider(group, "Speed", {
    Default = 50,
    Min = 0,
    Max = 100,
    Rounding = 0,
    Prefix = "$",
    Suffix = "%",
    Callback = function(value)
        print("Slider callback:", value)
    end,
})

speed:SetValue(75)
print(speed:GetValue())
speed:OnChanged(function(value)
    print("Slider changed:", value)
end)
```

`shared_info.AddSlider(group, name, config)`
- `group`: groupbox handle.
- `name`: string shown above the slider.
- `config.Default`: number used as the initial value.
- `config.Min`: lowest allowed number.
- `config.Max`: highest allowed number.
- `config.Rounding`: decimal precision used by the control.
- `config.Prefix`: optional string shown BEFORE the number, for example `$50`.
- `config.Suffix`: optional string shown AFTER the number, for example `50%` or `5s`.
- `config.Callback`: function(value) called when the slider value changes.
- Returns a slider handle.
- Handle methods: `GetValue()`, `SetValue(value)`, `OnChanged(callback)`, `RunChanged()`.
- Keep prefix/suffix semantics correct: currency-like prefixes go before the number; units such as `%` and `s` go after it.

## Input

```lua
local name = shared_info.AddInput(group, "Name", {
    Default = "LuWare",
    Placeholder = "Type your name...",
    Numeric = false,
    Finished = true,
    ClearTextOnFocus = false,
    Callback = function(value)
        print("Input callback:", value)
    end,
})

name:SetValue("Xynnn")
print(name:GetValue())
name:OnChanged(function(value)
    print("Input changed:", value)
end)
```

`shared_info.AddInput(group, name, config)`
- `group`: groupbox handle.
- `name`: string label for the input.
- `config.Default`: initial text string.
- `config.Placeholder`: hint shown while empty.
- `config.Numeric`: boolean; use `true` when the input should accept numeric entry.
- `config.Finished`: boolean controlling whether the callback waits for editing to finish.
- `config.ClearTextOnFocus`: boolean controlling whether existing text is cleared on focus.
- `config.Callback`: function(value) called when the input value is committed according to the control's `Finished` behavior.
- Returns an input handle.
- Handle methods: `GetValue()`, `SetValue(value)`, `OnChanged(callback)`, `RunChanged()`.

## Keybind

```lua
local key = shared_info.AddKeybind(group, "Action Key", {
    Default = "P",
    Mode = "Press",
    NoUI = false,
    Callback = function(value)
        print("Keybind callback:", value)
    end,
})

key:SetValue("K")
print(key:GetValue())
key:OnChanged(function(value)
    print("Keybind changed:", value)
end)
```

`shared_info.AddKeybind(group, name, config)`
- `group`: groupbox handle.
- `name`: string label for the key picker.
- `config.Default`: initial key value.
- `config.Mode`: string describing keybind behavior; `"Press"` is a documented example.
- `config.NoUI`: boolean controlling whether the keybind appears in the LuWare keybind display.
- `config.Callback`: function(value) called when the keybind value changes.
- Returns a keybind handle.
- Handle methods: `GetValue()`, `SetValue(value)`, `OnChanged(callback)`, `RunChanged()`.

## Colorpicker

```lua
local accent = shared_info.AddColorpicker(group, "Accent", {
    Default = Color3.fromRGB(110, 80, 255),
    Callback = function(color)
        print("Color callback:", color)
    end,
})

accent:SetValue(Color3.fromRGB(255, 80, 80))
print(accent:GetValue())
accent:OnChanged(function(color)
    print("Color changed:", color)
end)
```

`shared_info.AddColorpicker(group, name, config)`
- `group`: groupbox handle.
- `name`: string label for the colorpicker.
- `config.Default`: initial `Color3` value.
- `config.Callback`: function(color) called when the color changes.
- Returns a colorpicker handle.
- Handle methods: `GetValue()`, `SetValue(color)`, `OnChanged(callback)`, `RunChanged()`.
- `SetValue` should receive a `Color3` value.

## Notifications

Config form:

```lua
shared_info.Notify({
    Title = "Plugin Loaded",
    Description = "Everything is ready.",
    Time = 4,
})
```

Short form:

```lua
shared_info.Notify("Quick notification", 2)
```

`shared_info.Notify(...)`
- Config `Title`: string notification title.
- Config `Description`: string main notification text.
- Config `Time`: number controlling how long the notification remains visible.
- Short form first argument: notification text.
- Short form second argument: duration.

## Callbacks and handles

For controls that return handles:

```lua
local control = shared_info.AddToggle(group, "Enabled", {
    Default = false,
    Callback = function(value)
        print("Default Callback:", value)
    end,
})

print(control:GetValue())
control:SetValue(true)
control:OnChanged(function(value)
    print("OnChanged:", value)
end)
```

Use the returned handle from the element-creation call. Do not invent alternate handle methods.

Important callback rule:
- `Callback` belongs inside the element's config table.
- `Callback` receives the new value for Toggle, Slider, Input, Keybind, and Colorpicker.
- Button `Callback` receives no value.
- Use `OnChanged(callback)` for an additional listener after the handle has been created.

Documented names:
- `shared_info.Game`
- `shared_info.AddTab(name, icon)`
- `shared_info.AddGroupbox(tab, name, side)`
- `shared_info.AddToggle(group, name, config)`
- `shared_info.AddButton(group, name, config)`
- `shared_info.AddSlider(group, name, config)`
- `shared_info.AddInput(group, name, config)`
- `shared_info.AddKeybind(group, name, config)`
- `shared_info.AddColorpicker(group, name, config)`
- `shared_info.AddLabel(group, text)`

## Minimal valid plugin

```lua
if shared_info.Game ~= "Murder Mystery 2" then
    return
end

local tab = shared_info.AddTab("My Plugin", "sparkles")
local group = shared_info.AddGroupbox(tab, "Main", "Left")

local enabled = shared_info.AddToggle(group, "Enabled", {
    Default = false,
    Callback = function(value)
        shared_info.Notify("Enabled: " .. tostring(value), 2)
    end,
})

shared_info.AddButton(group, "Enable", {
    Callback = function()
        enabled:SetValue(true)
    end,
})

shared_info.Notify("Plugin loaded!", 3)
```

## Generation rules for AI

1. Use only the public names and signatures documented above.
2. Keep config keys exactly as documented and use the correct value types.
3. Do not invent unsupported options.
4. Return values are handles where the documentation says they are; call documented handle methods only.
5. For `AddTab`, the icon is a Lucide icon name string.
6. For `AddGroupbox`, `side` must be `"Left"` or `"Right"`.
7. Slider `Prefix` is rendered before the number; `Suffix` is rendered after it.
8. Put control callbacks inside `config.Callback`.
9. Use `SetValue()` only with a value appropriate to that element.
10. Use `GetValue()` to read a current control value.
11. Use `OnChanged(callback)` to attach another change listener after creation.
12. Prefer a small, working plugin over guessed APIs.
13. When documentation does not specify an option or behavior, do not assume it exists; ask for clarification or omit it.

The shared_info table

This is the public surface exposed to a plugin. Build plugins through this documented table and the handles returned by its functions.

Core idea: Plugins receive the documented functions for tabs, groupboxes, controls and utility features.
Game

shared_info.Game identifies the current supported game. Read it; do not overwrite it.

UI

AddTab, AddGroupbox and the element helpers create plugin UI through the documented API.

Utility

Notify displays a LuWare notification, while Kick routes through the LuWare error UI.

Handles

Callbacks & handles

Create a control with a default callback, listen for later changes, read its current value, and set a new value from code.

Pattern: Add... creates the element and returns a handle. Use GetValue() to read it, SetValue(value) to change it, and OnChanged(callback) to listen for changes.
local toggle = shared_info.AddToggle(group, "Enabled", {
    Default = true,
    Callback = function(value)
        print("Default callback:", value)
    end,
})

toggle:SetValue(false)
print("Current:", toggle:GetValue())

toggle:OnChanged(function(value)
    print("OnChanged:", value)
end)

toggle:SetValue(true)

Plugin environment

A plugin receives the documented public API through shared_info and a limited set of standard Lua/Roblox values needed to build plugins.

Public API

Use shared_info for plugin UI, notifications, game checks and the documented utility methods.

Built-in values

Common Lua helpers, standard libraries, tasks, enums and common Roblox value constructors are available for normal plugin code.

Keep plugins portable: build your plugin around the documented shared_info API so it behaves consistently with the LuWare plugin system.

Complete example

A complete .plug example that uses the public API, defaults, callbacks and value setters.

if shared_info.Game ~= "Murder Mystery 2" then
    return
end

local tab = shared_info.AddTab("Example Plugin", "sparkles")
local group = shared_info.AddGroupbox(tab, "All Elements", "Left")

local label = shared_info.AddLabel(group, "Ready")
label:SetText("Plugin loaded")

local toggle = shared_info.AddToggle(group, "Enabled", {
    Default = true,
    Callback = function(value)
        print("Toggle callback:", value)
    end,
})

shared_info.AddButton(group, "Toggle Value", {
    Callback = function()
        toggle:SetValue(not toggle:GetValue())
    end,
})

local slider = shared_info.AddSlider(group, "Speed", {
    Default = 50, Min = 0, Max = 100,
    Rounding = 0, Suffix = "%",
    Callback = function(value)
        print("Slider callback:", value)
    end,
})

local input = shared_info.AddInput(group, "Name", {
    Default = "LuWare",
    Placeholder = "Type something...",
    Callback = function(value)
        print("Input callback:", value)
    end,
})

local keybind = shared_info.AddKeybind(group, "Key", {
    Default = "P",
    Mode = "Press",
    NoUI = false,
    Callback = function(value)
        print("Keybind callback:", value)
    end,
})

local color = shared_info.AddColorpicker(group, "Color", {
    Default = Color3.fromRGB(110, 80, 255),
    Callback = function(value)
        print("Color callback:", value)
    end,
})

slider:OnChanged(function(value)
    print("Slider OnChanged:", value)
end)

input:SetValue("Xynnn")
keybind:SetValue("K")
color:SetValue(Color3.fromRGB(255, 80, 80))
slider:SetValue(75)

print("Toggle:", toggle:GetValue())
print("Slider:", slider:GetValue())
print("Input:", input:GetValue())
print("Keybind:", keybind:GetValue())
print("Color:", color:GetValue())

shared_info.Notify({
    Title = "Example Plugin",
    Description = "Loaded successfully.",
    Time = 4,
})
